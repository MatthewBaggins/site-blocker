# Site Blocker

Browser extension to block websites on Chromium/Brave.

## Install

1. Build: `npm run build`
2. Load `chrome://extensions/` → Developer mode → Load unpacked → select this folder
3. Click the extension icon and add domains to block

## Usage

- Enter a domain (e.g., `youtube.com`)
- Click "Add"
- Click "🗑️" to clear cache
- Click "×" to remove
